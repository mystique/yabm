# 02: 统一书签变化后的刷新协调

**What to build:** 新增、编辑、删除、排序、拖拽和 Chrome 外部变化都经过统一的刷新协调。书签树、展开状态、图标缓存和 WebDAV 状态不会因为不同入口各自刷新而产生不一致。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 本页执行书签操作并触发 Chrome 事件时，最终显示正确的树状态。
- [ ] 刷新期间再次发生变化时，最新变化最终能够显示。
- [ ] 新增或编辑后的目标文件夹仍按现有规则保持展开。
- [ ] 删除、排序和拖拽不会意外丢失其他已展开文件夹。
- [ ] 刷新失败仍显示用户可见的错误状态。
- [ ] 不新增没有真实用途的 Chrome adapter，不改变现有 script-tag 加载方式。
- [ ] 通过新增、编辑、删除、排序、拖拽和外部变化流程验证刷新结果。
