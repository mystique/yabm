# 01: 统一 WebDAV 配置会话

**What to build:** options 页面和书签页面使用同一套 WebDAV 配置会话规则：连接测试成功后才能保存；修改地址、用户名或密码后，旧测试结果失效；文件选择和新文件名规则保持一致。两个页面继续保留各自的表单、提示和弹窗表现。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 两个入口都不能保存未经成功测试的配置。
- [ ] 连接测试尚未完成时修改凭据，旧请求返回后不能错误地恢复保存资格。
- [ ] 修改地址、用户名或密码会让测试结果失效。
- [ ] 只修改目标文件名不会错误地让连接测试失效。
- [ ] 保存、清除和错误提示保持现有用户体验。
- [ ] 通过 options 页面和书签页面分别验证成功、失败、失效和保存流程。
