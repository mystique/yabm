# 03: 收拢拖拽 module 的完整生命周期

**What to build:** 拖拽 module 自己负责从开始、悬停、放置、取消到结束的状态和清理。用户取消拖拽、拖拽失败或异步操作尚未完成时，不会留下错误的高亮或拖拽残影。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 拖拽取消后，来源样式、目标高亮和拖拽残影都会清理。
- [ ] 异步检查目标期间发生 dragend，最终不会留下视觉状态。
- [ ] 不能把文件夹放入自己或自己的后代。
- [ ] 放到当前父文件夹时不会执行无意义移动。
- [ ] 移动失败时仍会清理拖拽视觉状态并显示错误。
- [ ] 书签行和文件夹行使用一致的拖拽收尾行为。
- [ ] 在 Chrome 中验证取消、失败、非法目标和成功移动流程。
